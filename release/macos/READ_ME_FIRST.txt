USB-helper {version} for macOS (universal)

This is an unsigned app. Drag USB-helper.app to the Applications folder.
If Gatekeeper blocks it and you trust this download, open Terminal and run:

   xattr -dr com.apple.quarantine /Applications/USB-helper.app

This clears quarantine only from USB-helper.app. It does not change Gatekeeper
settings or affect other files. Then open USB-helper.app from Applications.
No .NET installation is needed.
